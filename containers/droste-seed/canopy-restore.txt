# Packages stripped by canopy that droste-seed restores.
# See plans/canopy-migration.md R7 for audit and rationale.
# Verified against canopy:1.4.0 dpkg --get-selections (187 pkgs installed).
# 1.4.1 only adds systemd-resolved to canopy's PURGELIST per tenkei release
# notes; not in this list, so 1.4.1-compatible without re-verification.
# 1.5.1 is the current pinned version; compatibility has not been re-audited
# against canopy's PURGELIST — update this comment after verifying build.
# Note: coreutils is installed in a prior RUN layer in the Containerfile
# (must beat other postinsts to /usr/bin/ln etc.), not listed here.
#
# Intentionally NOT restored at seed (deferred to lint via
# oci/seed-oci-exclude.txt): openssh-server, openssh-sftp-server,
# ssh-import-id. These ship systemd units and need deb-systemd-helper
# (part of init-system-helpers, purged by canopy) for their postinsts
# to enable services correctly. Installing them at seed — where systemd
# is absent — produces silent half-broken enable state that can't be
# recovered by a later `systemctl enable`. Canopy clusters init-family
# + openssh together in its PURGELIST for exactly this reason; we
# restore them together at lint where systemd + init-system-helpers
# land in the same apt transaction. App tiers (fiber/sheet/page/etc.)
# inherit from seed and don't need sshd (process containers), so they
# stay lean.
